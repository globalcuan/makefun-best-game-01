# VOID HARVEST

VOID HARVEST is a neon twin-stick arena survival shooter set in a dark, star-filled sector. Pilot a nimble ship through escalating waves of chasers, ranged enemies, splitting horrors and a radial-firing boss every fifth wave; collect glowing shards to level up and shape your build while synthesised arcade audio punctuates the fight.

## How to play

Move with **WASD** or the **arrow keys**, aim with the mouse, and hold the mouse button or **Space** to fire. Use **Shift** to dash, **P** or **Esc** to pause, and **M** to mute. Choose one of three upgrades when you level up.

## Run locally

Run `node serve.ts`, then open [http://localhost:8080](http://localhost:8080).
